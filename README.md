# Claude Code 설치집 ☁️

윈도우에서 **Claude Code**를 설치하는 방법을, 비개발자도 따라할 수 있게 일상의 비유로 풀어낸 친절한 안내 랜딩페이지입니다.

> 터미널이 뭔지 몰라도 괜찮아요. 새 가전제품 설명서 보듯, 한 단계씩 따라오면 끝나요.

## 무엇이 담겼나

- **이게 뭔가요** — Claude Code를 일상 언어로 소개
- **준비물 4가지** — Windows 버전 · Node.js · Git · PowerShell (장보기 비유)
- **두 갈래 길** — 터미널 전역설치 vs VS Code 확장, 인터랙티브 선택
- **단계별 설치 가이드** — 선택한 방법에 맞춰 펼쳐지는 5단계 (복사 버튼 포함)
- **한눈 비교표** — 어떤 방법이 나에게 맞을까
- **인터랙티브 체크리스트** — 진행률이 차오르는 추천 순서
- **FAQ 아코디언** — 자주 막히는 6가지 지점

## 기술

- 단일 `index.html` — 의존성 0, 프레임워크 0
- 따뜻한 종이 질감 + Claude 코랄 톤 에디토리얼 디자인
- 스크롤 reveal · 탭 전환 · 코드 복사 · 아코디언 · 진행률 등 인터랙션
- 모바일 반응형, `prefers-reduced-motion` 지원
- 폰트: Gowun Batang(헤드라인) · Pretendard(본문) · JetBrains Mono(코드)
