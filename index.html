01
먼저, 이게 뭔가요

Claude Code가 뭐길래
내 컴퓨터에 들이나요?

쉽게 말하면 — 내 컴퓨터 파일을 직접 보고, 고치고, 만들어 줄 수 있는 AI 동료예요. 채팅창에 글만 주고받는 AI가 아니라, 실제로 손을 움직여 일을 해주는 게 핵심이죠.

💬

무엇을 하나요

"이 폴더 정리해줘", "이 파일 고쳐줘"처럼 평소 말로 부탁하면, AI가 직접 내 컴퓨터에서 그 일을 처리해 줘요.

💡 비유하면 — 말귀 알아듣는 조수가 책상 옆에 앉아있는 셈
🛠️

어떻게 쓰나요

설치만 끝나면 두 가지 방식으로 부를 수 있어요. 검은 화면(터미널)에서 부르거나, 익숙한 편집 프로그램 안에서 부르거나.

💡 비유하면 — 같은 조수를 전화로 부르느냐 옆자리에 앉히느냐의 차이
🌱

왜 비개발자에게도

문서 정리, 자료 변환, 간단한 자동화까지 — 코드를 몰라도 "부탁"만 할 줄 알면 점점 더 많은 일을 맡길 수 있어요.

💡 비유하면 — 처음엔 심부름, 익숙해지면 살림 전체를 맡기는 가사도우미

02 · 먼저 준비할 것

설치 전, 장바구니에
담아둘 준비물 4가지

요리를 시작하기 전에 재료와 도구를 먼저 꺼내두면 훨씬 수월하죠. 설치도 똑같아요. 아래 4가지를 순서대로 챙겨두면 중간에 헤맬 일이 거의 없어요.

1
🪟
가장 먼저 확인

Windows 버전

Claude Code는 Windows 10 (버전 1809) 이상을 기준으로 안내돼요. 너무 오래된 윈도우라면 먼저 업데이트가 필요해요.

🏠 비유 — 새 가구를 들이기 전에 현관문이 규격에 맞는지 재보는 단계예요.
2
⚙️
핵심 엔진

Node.js (LTS)

터미널 방식의 Claude Code는 Node.js라는 엔진 위에서 돌아가요. 공식 사이트에서 LTS 버전을 받으세요.

🍳 비유 — 요리를 하려면 먼저 가스레인지가 있어야 하죠. Node.js가 바로 그 가스레인지예요.
3
📚
권장 도구

Git for Windows

꼭 필요한 건 아니지만 강력 권장이에요. 설치 마법사에서는 거의 다 기본값(Next)으로 진행하면 됩니다.

⏳ 비유 — 작업한 내용을 차곡차곡 저장해주는 타임캡슐. 있으면 두고두고 든든해요.
4
⌨️
명령 입력 창구

PowerShell

설치 명령을 입력하는 검은 화면이에요. 윈도우에 기본으로 들어있어서 따로 설치할 필요는 없어요. (CMD도 가능)

🗣️ 비유 — 컴퓨터에게 말을 거는 대화창. 우리가 글로 부탁하면 컴퓨터가 알아듣고 움직여요.

03 · 갈림길

설치 방법은 두 갈래,
마음에 드는 길로 가세요

목적지는 똑같아요. 가는 길만 다를 뿐이죠. 아래 카드를 눌러 길을 골라보면, 그 방법에 딱 맞는 설치 단계가 아래에 펼쳐져요.

파워 유저 추천

① 터미널 전역설치

명령어 한 줄로 직접 설치

검은 화면(PowerShell)에 명령어를 붙여넣어 설치해요. 한 번 세팅하면 어느 폴더에서든 claude만 치면 불러올 수 있어요.

  • 어디서나 빠르게 호출
  • 자동화·반복 작업에 유리
  • Node.js 준비가 먼저 필요
처음이라면 추천

② VS Code 확장 프로그램

버튼 클릭만으로 설치

VS Code라는 무료 편집 프로그램 안에 Claude Code를 붙여 써요. 검은 화면이 부담스럽다면 이쪽이 훨씬 편안해요.

  • 화면에서 버튼으로 설치
  • 명령어 외울 필요 적음
  • 결과를 눈으로 보기 편함

👇 길을 고르면 아래 설치 단계가 그 길에 맞춰 바뀌어요

04
04 · 따라하기

자, 한 단계씩
같이 가볼까요

1

Node.js부터 설치하기 (가스레인지 들이기)

터미널 방식은 Node.js라는 엔진 위에서 돌아가요. 이걸 먼저 해두면 뒤가 훨씬 덜 헷갈려요.

  1. Node.js 공식 사이트에 접속해요.
  2. LTS 버전 버튼을 눌러 받아요. LTS = 오래 검증된 안정 버전, 갓 나온 실험판 말고 스테디셀러라고 생각하세요.
  3. 받은 .msi 파일을 더블클릭해요.
  4. 설치 마법사는 거의 Next → Next → Install → Finish 순서로 누르면 끝나요.

설치가 끝나면 PowerShell을 열고 잘 들어왔는지 확인해 봐요.

Windows PowerShell
PS> node -v
PS> npm -v
✅ 이렇게 나오면 성공 — v20.x.x 처럼 두 줄 모두 버전 숫자가 보이면 가스레인지가 잘 들어온 거예요.
🌿Git도 이 단계에서 같이 설치해두면 좋아요. 설치 마법사는 대부분 기본값(Next)으로 넘어가면 됩니다.
2

PowerShell을 관리자 권한으로 열기

설치 명령은 컴퓨터에 무언가를 새로 들이는 작업이라, "관리자" 권한이 필요해요.

  1. 시작 메뉴에서 PowerShell을 검색해요.
  2. 목록에서 마우스 오른쪽 클릭 → 관리자 권한으로 실행을 눌러요.
  3. "이 앱이 변경하도록 허용할까요?"가 뜨면 예를 눌러요.
🔑비유 — 관리자 권한은 우리 집 현관 마스터키예요. 새 가구(프로그램)를 들일 땐 잠깐 이 키가 필요하답니다.
3

설치 명령어 한 줄 붙여넣기

이제 핵심이에요. 아래 명령어를 복사해서 PowerShell 창에 붙여넣고 Enter를 누르세요. 설치가 자동으로 진행돼요.

Windows PowerShell · 관리자
PS> irm https://claude.ai/install.ps1 | iex
📦비유 — 이 한 줄은 "택배 주문 버튼"이에요. 누르면 컴퓨터가 알아서 Claude Code를 받아와 설치까지 끝내줘요. 잠시 기다리면 됩니다.
4

제대로 도착했는지 버전 확인

설치가 끝났다는 메시지가 보이면, 정말 잘 들어왔는지 송장을 찍어봐요.

Windows PowerShell
PS> claude --version
✅ 이렇게 나오면 성공 — 버전 번호가 한 줄 출력되면 설치 완료예요! claude : 용어가 인식되지 않습니다 라고 나오면 PowerShell을 완전히 닫았다 다시 열어보세요.
5

처음 실행하고 로그인하기

마지막이에요. claude를 입력해 실행하면, 처음엔 로그인이나 인증 안내가 떠요. 화면 안내를 그대로 따라가면 끝납니다.

Windows PowerShell
PS> claude
🎉다 됐어요! 이제 AI 동료가 입주를 마쳤습니다. 어느 폴더에서든 claude만 치면 부를 수 있어요.
1

VS Code 설치하고 열기 (작업 책상 들이기)

VS Code는 마이크로소프트가 만든 무료 편집 프로그램이에요. AI 동료가 앉을 책상이라고 생각하면 돼요.

  1. 검색창에 "VS Code 다운로드"를 검색해 공식 사이트로 들어가요.
  2. Windows용 설치 파일을 받아 더블클릭하고, 기본값으로 설치해요.
  3. 설치가 끝나면 VS Code를 실행해요.
🪑비유 — 검은 터미널 화면이 부담스럽다면, 이 방법은 밝고 익숙한 책상 위에서 AI를 부르는 느낌이라 훨씬 편안해요.
2

확장 프로그램 메뉴 열기

VS Code에는 기능을 덧붙이는 "확장 프로그램" 가게가 있어요. 거기서 Claude Code를 찾을 거예요.

  1. 왼쪽 사이드바에서 네모 4개 모양의 Extensions 아이콘을 눌러요.
  2. 또는 키보드로 Ctrl + Shift + X를 동시에 눌러요.
🧩비유 — 확장 프로그램 가게는 스마트폰의 앱스토어와 똑같아요. 필요한 기능을 검색해서 "설치" 버튼만 누르면 되죠.
3

Claude 검색하고 설치 버튼 누르기

이제 가게에서 우리가 찾는 동료를 검색할 차례예요.

  1. 검색창에 Claude Code 또는 Claude를 입력해요.
  2. 게시자(Publisher)가 Anthropic으로 표시된 정품을 찾아요. — 이게 가장 중요해요!
  3. 그 확장 프로그램의 Install 버튼을 눌러요.
🔎비유 — 같은 이름의 짝퉁이 섞여 있을 수 있어요. 정품 마크(Anthropic)를 꼭 확인하는 건, 택배에서 정품 인증 스티커를 보는 것과 같아요.
4

VS Code 다시 시작하기

새 기능이 제대로 자리잡으려면 프로그램을 한 번 새로고침 해줘야 해요.

  1. 설치가 끝나면 VS Code를 완전히 닫았다 다시 열어요.
  2. 또는 Ctrl + Shift + P를 누르고 Reload Window를 검색해 실행해요.
🔄비유 — 새 가구를 들인 뒤 방을 한 바퀴 둘러보며 자리를 잡는 것과 같아요. 잠깐의 새로고침이면 충분해요.
5

실행하고 첫 인사 나누기

다 됐어요! VS Code 안에서 Claude Code를 열고, 안내에 따라 로그인하면 끝입니다.

  1. VS Code 화면에서 Claude Code 패널을 열어요. (설치 후 보통 안내가 떠요)
  2. 로그인·인증 안내가 뜨면 화면 그대로 따라가요.
  3. 필요하면 확장 설정에서 터미널 사용 옵션을 켜요. 문서·영상에서 함께 쓰는 경우가 많아요.
🎉입주 완료! 이제 VS Code 안에서 언제든 AI 동료에게 일을 부탁할 수 있어요.

07 · 자주 막히는 곳

여기서 많이들 멈춰요 —
미리 알아두면 안 막혀요

설치하다 보면 누구나 한 번쯤 갸웃하게 되는 지점들이 있어요. 자주 나오는 질문만 모았어요.

Q PowerShell, CMD, Git Bash… 뭐가 다른 거예요?
모두 "컴퓨터에게 명령을 입력하는 창"이에요. 같은 목적의 다른 창구라고 보면 돼요. 공식 문서 기준으로 Windows에서는 PowerShell 설치 명령이 가장 단순하고 안내도 가장 많아요. 그래서 이 가이드도 PowerShell을 기준으로 설명했어요. CMD로도 설치는 가능해요.
Q claude를 쳤더니 "인식되지 않습니다"라고 나와요.
설치 직후 가장 흔한 상황이에요. 컴퓨터가 새로 들어온 명령어를 아직 모르는 상태거든요. PowerShell 창을 완전히 닫았다가 다시 열어보세요. 대부분 이걸로 해결돼요. 그래도 안 되면 컴퓨터를 한 번 재시작한 뒤 다시 시도해 보세요.
Q Node.js, 꼭 설치해야 하나요?
터미널 전역설치 방식은 Node.js라는 엔진 위에서 돌아가기 때문에 먼저 설치해두는 걸 권장해요. 요리로 치면 가스레인지 같은 존재라, 없으면 불을 못 켜는 셈이죠. 미리 깔아두면 설치 과정이 훨씬 매끄러워요.
Q 윈도우 버전이 너무 낮으면 어떻게 하나요?
Claude Code는 Windows 10 (버전 1809) 이상을 기준으로 안내돼요. 그보다 낮다면, 윈도우 설정 → 업데이트에서 먼저 최신 상태로 올린 뒤 설치를 진행하세요. 현관문 규격이 맞아야 새 가구가 들어올 수 있는 것과 같아요.
Q 두 방법을 다 설치해도 괜찮나요?
네, 괜찮아요. 다만 처음에는 한 가지 방법으로 익숙해진 뒤 필요해지면 다른 방법을 더해보는 걸 추천해요. 한꺼번에 두 길을 가면 어디서 막혔는지 헷갈리기 쉽거든요. 하나씩, 천천히가 정답이에요.
Q 설치하다 처음 보는 영어 메시지가 떠요.
당황하지 않아도 돼요. 설치 마법사의 메시지는 대부분 "다음으로 넘어갈까요?"를 묻는 거예요. 특별한 안내가 없다면 Next(다음) → Install(설치) → Finish(완료) 흐름으로 진행하면 됩니다. 정 모르겠는 메시지가 뜨면, 그 문장을 그대로 복사해 검색해 보는 것도 좋은 방법이에요.
