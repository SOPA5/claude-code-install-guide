01
먼저, 이게 뭔가요

Claude Code가 뭐길래
내 컴퓨터에 들이나요?

쉽게 말하면 — 내 컴퓨터 파일을 직접 보고, 고치고, 만들어 줄 수 있는 AI 동료예요. 채팅창에 글만 주고받는 AI가 아니라, 실제로 손을 움직여 일을 해주는 게 핵심이죠.

💬

무엇을 하나요

"이 폴더 정리해줘", "이 파일 고쳐줘"처럼 평소 말로 부탁하면, AI가 직접 내 컴퓨터에서 그 일을 처리해 줘요.

💡 비유하면 — 말귀 알아듣는 조수가 책상 옆에 앉아있는 셈
🛠️

어떻게 쓰나요

설치만 끝나면 두 가지 방식으로 부를 수 있어요. 검은 화면(터미널)에서 부르거나, 익숙한 편집 프로그램 안에서 부르거나.

💡 비유하면 — 같은 조수를 전화로 부르느냐 옆자리에 앉히느냐의 차이
🌱

왜 비개발자에게도

문서 정리, 자료 변환, 간단한 자동화까지 — 코드를 몰라도 "부탁"만 할 줄 알면 점점 더 많은 일을 맡길 수 있어요.

💡 비유하면 — 처음엔 심부름, 익숙해지면 살림 전체를 맡기는 가사도우미

02 · 먼저 준비할 것

설치 전, 장바구니에
담아둘 준비물 4가지

좋은 소식 — 요즘 권장 설치법은 준비물이 거의 없어요. 윈도우와 PowerShell만 있으면 명령어 한 줄로 끝나거든요. 아래 4가지만 가볍게 확인하고 넘어가요.

1
🪟
가장 먼저 확인

Windows 버전

Claude Code는 Windows 10 (버전 1809) 이상을 기준으로 안내돼요. 너무 오래된 윈도우라면 먼저 업데이트가 필요해요.

🏠 비유 — 새 가구를 들이기 전에 현관문이 규격에 맞는지 재보는 단계예요.
2
⌨️
이미 설치돼 있음

PowerShell

설치 명령을 입력하는 검은 화면이에요. 윈도우에 기본으로 들어있어서 따로 받을 필요가 없어요. (CMD로도 가능)

🗣️ 비유 — 컴퓨터에게 말을 거는 대화창. 우리가 글로 부탁하면 컴퓨터가 알아듣고 움직여요.
3
📚
있으면 좋음 · 선택

Git for Windows

설치에 꼭 필요하진 않지만 같이 깔아두길 권장해요. 설치 마법사는 거의 다 기본값(Next)으로 진행하면 됩니다.

⏳ 비유 — 작업한 내용을 차곡차곡 저장해주는 타임캡슐. 있으면 두고두고 든든해요.
4
⚙️
npm 방식만 · 선택

Node.js (LTS)

아래 ① 권장 설치(명령어 한 줄)에는 필요 없어요. ② npm 방식으로 설치하려는 분만 공식 사이트에서 LTS 버전을 미리 받아두면 돼요.

🍳 비유 — 요리용 가스레인지 같은 엔진. 요즘 권장 설치법은 이 엔진 없이도 되니, 없으면 그냥 넘어가도 괜찮아요.

1

PowerShell 열기 (컴퓨터와 대화할 창 켜기)

설치 명령을 입력할 검은 화면을 열 거예요. 윈도우에 기본으로 들어있어서 따로 받을 필요 없어요.

  1. 키보드에서 Win + X를 동시에 눌러요.
  2. 뜨는 메뉴에서 "터미널" 또는 "Windows PowerShell"을 눌러요.
🔑관리자 권한, 안 찾아도 돼요 — 요즘 권장 설치법은 일반 권한으로 충분해요. "관리자 권한으로 실행"을 굳이 고를 필요 없이 그냥 열면 됩니다.
2

설치 명령어 한 줄 붙여넣기

이제 핵심이에요. 아래 한 줄을 복사해서 PowerShell 창에 붙여넣고 Enter를 누르세요. 나머지는 컴퓨터가 알아서 받아와 설치해요.

Windows PowerShell
PS> irm https://claude.ai/install.ps1 | iex
📦비유 — 이 한 줄은 "택배 주문 버튼"이에요. 누르면 컴퓨터가 알아서 Claude Code를 받아와 설치까지 끝내줘요. 이 방법은 Node.js 같은 준비물도 필요 없어요.
🚧빨간 글씨로 "스크립트를 실행할 수 없습니다"가 뜨면 윈도우 보안 설정 때문이에요. 아래 막혔을 때 — 02번에서 한 줄로 풀 수 있어요.
3

버전 확인 (택배 송장 찍어보기)

설치 완료 메시지가 보이면, 정말 잘 들어왔는지 확인해요. 먼저 PowerShell을 완전히 닫았다가 새로 연 다음 입력하세요. (창을 새로 열어야 컴퓨터가 새 프로그램을 알아봐요)

Windows PowerShell
PS> claude --version
✅ 이렇게 나오면 성공 — 버전 번호가 한 줄 출력되면 설치 완료예요!
🚧claude : 인식되지 않습니다가 뜨나요? 아주 흔한 일이라 당황 안 해도 돼요. 아래 막혔을 때 — 01번 (PATH)에서 순서대로 해결돼요.
4

처음 실행하고 로그인하기

마지막이에요. claude를 입력해 실행하면, 처음엔 로그인이나 인증 안내가 떠요. 화면 안내를 그대로 따라가면 끝납니다.

Windows PowerShell
PS> claude
🎉다 됐어요! 이제 AI 동료가 입주를 마쳤습니다. 어느 폴더에서든 claude만 치면 부를 수 있어요.

🛠️ 다른 설치 방법도 있어요 (선택)

위 방법(① 권장 설치)이 가장 간단하고 자동 업데이트까지 돼요. 다만 환경에 따라 이렇게도 설치할 수 있어요.

  • WinGet — 윈도우 기본 앱 설치 도구를 쓴다면
    winget install Anthropic.ClaudeCode
  • npm — Node.js(18 버전 이상)가 이미 깔려 있다면
    npm install -g @anthropic-ai/claude-code

⚠️ WinGet·npm 방식은 자동 업데이트가 안 돼서, 가끔 직접 최신 버전으로 갱신해줘야 해요. 특별한 이유가 없다면 위 ① 권장 설치를 쓰는 걸 추천해요.

1

VS Code 설치하고 열기 (작업 책상 들이기)

VS Code는 마이크로소프트가 만든 무료 편집 프로그램이에요. AI 동료가 앉을 책상이라고 생각하면 돼요.

  1. 검색창에 "VS Code 다운로드"를 검색해 공식 사이트로 들어가요.
  2. Windows용 설치 파일을 받아 더블클릭하고, 기본값으로 설치해요.
  3. 설치가 끝나면 VS Code를 실행해요.
📌이미 VS Code가 있다면 최신 버전인지 확인해 주세요. (도움말 → 업데이트 확인) 너무 오래된 버전에서는 Claude Code 확장이 작동하지 않을 수 있어요.
🪑비유 — 검은 터미널 화면이 부담스럽다면, 이 방법은 밝고 익숙한 책상 위에서 AI를 부르는 느낌이라 훨씬 편안해요.
2

확장 프로그램 메뉴 열기

VS Code에는 기능을 덧붙이는 "확장 프로그램" 가게가 있어요. 거기서 Claude Code를 찾을 거예요.

  1. 왼쪽 사이드바에서 네모 4개 모양의 Extensions 아이콘을 눌러요.
  2. 또는 키보드로 Ctrl + Shift + X를 동시에 눌러요.
🧩비유 — 확장 프로그램 가게는 스마트폰의 앱스토어와 똑같아요. 필요한 기능을 검색해서 "설치" 버튼만 누르면 되죠.
3

Claude 검색하고 설치 버튼 누르기

이제 가게에서 우리가 찾는 동료를 검색할 차례예요.

  1. 검색창에 Claude Code를 입력해요.
  2. 게시자(Publisher)가 Anthropic, 확장 이름이 Claude Code인 정품을 찾아요. — 이게 가장 중요해요!
  3. 그 확장의 Install 버튼을 눌러요.
🔎비유 — 비슷한 이름이 섞여 있을 수 있어요. 게시자 Anthropic을 확인하는 건 택배의 정품 인증 스티커를 보는 것과 같아요. (확장 ID는 anthropic.claude-code)
🎁한 번에 끝나요 — 이 확장 하나만 설치하면, 터미널에서 쓰는 claude 명령까지 함께 깔려요. 따로 더 설치할 게 없습니다.
4

VS Code 다시 시작하기

새 기능이 제대로 자리잡으려면 프로그램을 한 번 새로고침 해줘야 해요.

  1. 설치가 끝나면 VS Code를 완전히 닫았다 다시 열어요.
  2. 또는 Ctrl + Shift + P를 누르고 Reload Window를 검색해 실행해요.
🔄비유 — 새 가구를 들인 뒤 방을 한 바퀴 둘러보며 자리를 잡는 것과 같아요. 잠깐의 새로고침이면 충분해요.
5

실행하고 첫 인사 나누기

다 됐어요! VS Code 안에서 Claude Code를 열고, 안내에 따라 로그인하면 끝입니다.

  1. 아무 파일을 하나 연 다음, 화면 오른쪽 위의 ⚡ 아이콘을 눌러요. Claude Code 패널이 열려요.
  2. 아이콘이 안 보이면 Ctrl + Shift + P를 누르고 Claude Code를 검색해 열어도 돼요.
  3. 패널에서 Sign in 버튼을 눌러, 안내대로 Claude 계정으로 로그인해요.
💡⚡ 아이콘이 안 보이나요? 이 아이콘은 파일을 열어야 나타나요. 폴더만 연 상태라면 안 보일 수 있으니, 아무 파일이나 하나 열어보세요.
🎉입주 완료! 이제 VS Code 안에서 언제든 AI 동료에게 일을 부탁할 수 있어요.

05 · 막혔을 때

설치하다 막혔나요?
증상별로 차근차근 풀어봐요

윈도우 설치는 PATH·보안 설정·백신 때문에 한 번씩 멈출 수 있어요. 당황하지 말고, 아래에서 내 증상과 같은 칸을 찾아 위에서부터 순서대로 따라 하면 됩니다.

🩺

막막하면 가장 먼저 — claude doctor

Claude Code에는 스스로 건강검진을 하는 명령이 있어요. 설치 상태·PATH·로그인·설정을 한 번에 점검해서 무엇이 문제인지 짚어줘요. 어디가 잘못됐는지 모를 땐 이것부터 실행해 보세요.

claude doctor
01

claude를 쳤더니 "인식되지 않습니다"

이런 메시지가 떠요 claude : 'claude' 용어가 cmdlet, 함수, 스크립트 파일… 이름으로 인식되지 않습니다.

🔎 원인 — 설치는 됐는데, 윈도우가 claude가 어디 있는지 모르는 상태예요. 프로그램은 보통 C:\Users\(내이름)\.local\bin 폴더에 들어가는데, 이 위치가 "PATH"라는 주소록에 등록되지 않아서 그래요.

해결 순서
  1. PowerShell을 완전히 닫았다가 새로 열어요. 설치 직후엔 주소록 갱신이 안 돼 있어서, 열에 여덟은 이걸로 해결돼요.
  2. 그래도면 claude doctor를 실행해, PATH 항목에 ✗ 표시가 있는지 확인해요.
  3. 여전히면 PATH 주소록에 직접 등록해요. PowerShell에 아래 두 줄을 붙여넣고 Enter:
    Windows PowerShell · PATH 등록
    $p=[Environment]::GetEnvironmentVariable('PATH','User')
[Environment]::SetEnvironmentVariable('PATH',"$p;$env:USERPROFILE\.local\bin",'User')
  4. 다시 PowerShell을 완전히 닫고 새로 연 뒤 claude --version으로 확인해요.
🖱️마우스로 하고 싶다면 — Win+X → 시스템 → 고급 시스템 설정 → 환경 변수 → "사용자 변수"의 Path 선택 → 편집 → 새로 만들기 → %USERPROFILE%\.local\bin 입력 → 확인. 그다음 터미널을 새로 열면 돼요.
02

설치 명령이 빨간 글씨로 거부돼요

이런 메시지가 떠요 … 이 시스템에서 스크립트를 실행할 수 없으므로 … (UnauthorizedAccess)

🔎 원인 — 윈도우가 보안을 위해 외부 스크립트 실행을 기본으로 막아둔 상태예요. "실행 정책(ExecutionPolicy)"이라고 불러요.

해결 순서
  1. 아래 명령을 붙여넣어, 지금 열린 이 창에서만 잠깐 빗장을 풀어요.
    Windows PowerShell
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  2. 이어서 설치 명령을 다시 붙여넣어요.
    Windows PowerShell
    irm https://claude.ai/install.ps1 | iex
🔒안심하세요 — -Scope Process는 "지금 열린 이 창에서만" 풀린다는 뜻이에요. 창을 닫으면 원래 보안 설정으로 자동 복구돼요.
03

다운로드가 안 되거나 중간에 멈춰요

이런 메시지가 떠요 Could not resolve host / Failed to fetch… / 연결 시간 초과

🔎 원인 — 인터넷 연결이 불안정하거나, 회사·학교 네트워크의 방화벽·프록시가 설치 파일 다운로드를 막고 있어요.

해결 순서
  1. 브라우저로 아무 사이트나 열어 인터넷이 정상인지 먼저 확인해요.
  2. 회사·학교 와이파이를 쓰고 있다면, 휴대폰 핫스팟 같은 다른 네트워크로 바꿔 다시 시도해요. (사내망 차단이 가장 흔한 원인이에요)
  3. 그래도면 윈도우 기본 설치 도구 WinGet으로 우회해 봐요:
    Windows PowerShell
    winget install Anthropic.ClaudeCode
  4. 꼭 사내망을 써야 한다면, 회사 IT 담당자에게 프록시 주소를 물어보세요. 그 주소를 설정하면 설치할 수 있어요.
04

백신(보안 프로그램)이 설치를 막아요

이런 메시지가 떠요 다른 프로세스가 사용 중이므로 파일에 액세스할 수 없습니다 / 설치 중 멈춤

🔎 원인 — 백신(안티바이러스)이 방금 받은 설치 파일을 검사하느라 잠깐 잠가둔 상태예요. 나쁜 신호는 아니에요.

해결 순서
  1. 1~2분 기다렸다가 설치 명령을 다시 실행해요. 검사가 끝나면 잠금이 풀려요.
  2. 그래도면 백신을 잠깐 끄고 설치한 뒤, 끝나면 다시 켜요.
  3. 여전히면 받다 만 파일을 비우고 새로 받아요:
    Windows PowerShell
    Remove-Item -Recurse -Force "$env:USERPROFILE\.claude\downloads"

VS Code 확장은 깔았는데 패널이 안 보여요

이런 상황이에요 ⚡ 아이콘이 안 보임 / 확장을 설치했는데 아무 변화가 없음

🔎 원인 — 대부분 파일을 안 열었거나, VS Code 버전이 낮거나, 새로고침이 필요한 경우예요.

해결 순서
  1. 아무 파일을 하나 열어요. ⚡ 아이콘은 파일을 열어야 오른쪽 위에 나타나요. (폴더만 열면 안 보여요)
  2. VS Code 버전을 확인해요. 도움말(Help) → 정보(About) — 너무 옛 버전이면 code.visualstudio.com에서 최신 버전을 받아요.
  3. 창을 새로고침해요. Ctrl+Shift+P → Developer: Reload Window 실행, 또는 VS Code를 완전히 닫았다 다시 열어요.
  4. 그래도면 VS Code 하단 오른쪽의 Claude Code 버튼을 눌러서도 열 수 있어요.
🆘 위로도 안 풀렸다면 — PowerShell에서 claude doctor를 실행해 나온 내용을 캡처해 두고, 공식 설치 문제 해결 문서를 참고하세요: code.claude.com · 설치 문제 해결 ↗

09 · 자주 막히는 곳

여기서 많이들 멈춰요 —
미리 알아두면 안 막혀요

설치하다 보면 누구나 한 번쯤 갸웃하게 되는 지점들이 있어요. 자주 나오는 질문만 모았어요.

Q PowerShell, CMD, Git Bash… 뭐가 다른 거예요?
모두 "컴퓨터에게 명령을 입력하는 창"이에요. 같은 목적의 다른 창구라고 보면 돼요. 공식 문서 기준으로 Windows에서는 PowerShell 설치 명령이 가장 단순하고 안내도 가장 많아요. 그래서 이 가이드도 PowerShell을 기준으로 설명했어요. CMD로도 설치는 가능해요.
Q WSL이나 리눅스를 꼭 깔아야 하나요?
아니요. Claude Code는 윈도우에서 그대로 동작해요. 예전엔 WSL(윈도우 안의 리눅스)을 권하던 시절도 있었지만, 지금은 이 가이드대로 PowerShell에서 바로 설치하면 됩니다. WSL은 리눅스 도구를 함께 쓰는 분들을 위한 선택지일 뿐, 필수가 아니에요.
Q Node.js, 꼭 설치해야 하나요?
권장 설치법(명령어 한 줄)에는 필요 없어요. 그 방법은 Node.js 없이도 동작하는 완결된 프로그램을 통째로 받아오거든요. Node.js가 필요한 건 npm으로 설치하는 경우뿐이에요. 처음이라면 Node.js는 신경 쓰지 않아도 됩니다.
Q 윈도우 버전이 너무 낮으면 어떻게 하나요?
Claude Code는 Windows 10 (버전 1809) 이상을 기준으로 안내돼요. 그보다 낮다면, 윈도우 설정 → 업데이트에서 먼저 최신 상태로 올린 뒤 설치를 진행하세요. 현관문 규격이 맞아야 새 가구가 들어올 수 있는 것과 같아요.
Q 두 방법을 다 설치해도 괜찮나요?
네, 괜찮아요. 다만 처음에는 한 가지 방법으로 익숙해진 뒤 필요해지면 다른 방법을 더해보는 걸 추천해요. 한꺼번에 두 길을 가면 어디서 막혔는지 헷갈리기 쉽거든요. 하나씩, 천천히가 정답이에요.
Q 설치하다 처음 보는 영어 메시지가 떠요.
당황하지 않아도 돼요. 설치 마법사의 메시지는 대부분 "다음으로 넘어갈까요?"를 묻는 거예요. 특별한 안내가 없다면 Next(다음) → Install(설치) → Finish(완료) 흐름으로 진행하면 됩니다. 정 모르겠는 메시지가 뜨면, 그 문장을 그대로 복사해 검색해 보는 것도 좋은 방법이에요.
Q 최신 버전으로 업데이트하려면요?
권장 설치법(명령어 한 줄)으로 깔았다면 알아서 자동 업데이트되니 신경 쓰지 않아도 돼요. VS Code 확장도 자동으로 최신화됩니다. WinGet으로 깔았다면 winget upgrade Anthropic.ClaudeCode, npm이면 npm install -g @anthropic-ai/claude-code@latest로 갱신해요. 지금 버전은 claude --version으로 확인할 수 있어요.
Q 삭제하고 싶으면 어떻게 하나요?
VS Code 확장은 확장 메뉴에서 Uninstall을 누르면 돼요. 터미널로 설치한 경우엔 PowerShell에서 Remove-Item "$env:USERPROFILE\.local\bin\claude.exe" -Force로 프로그램을, Remove-Item "$env:USERPROFILE\.claude" -Recurse -Force로 설정까지 지울 수 있어요. WinGet은 winget uninstall Anthropic.ClaudeCode, npm은 npm uninstall -g @anthropic-ai/claude-code로 제거해요.
